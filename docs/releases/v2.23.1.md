This patch release fixes stale evacuation recommendations after a node leaves maintenance mode.

## Fix

- **Recommendations refresh when maintenance changes.** While a node is in maintenance, recommendations evacuate every guest on it, including stopped guests and guests tagged `ignore`. Taking the node out of maintenance used to leave that list in place until the next scheduled run, up to 15 minutes later, so powered-off guests still showed as moves. Putting a node into maintenance or taking it out now regenerates recommendations straight away, and the list is current within about 20 seconds.

## Upgrading

Update from the update window (click the version number in the top bar). The updater backs up the database, settings and web files, installs the tested web bundle, restarts ProxBalance and rolls back automatically if it doesn't come back healthy. Nothing else is needed.
