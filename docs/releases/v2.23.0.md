This release makes the Overview's layout more flexible, gives it widgets from the Detailed dashboard, and replaces wall mode with an Overview preset you show full screen with the browser's F11.

## Wall screen

- **Wall mode is removed.** It scaled the Overview into the screen, which didn't work for layouts taller than the screen. The top-bar button is gone, and `#/wall` now opens the Overview.
- **For a screen on the wall**, pick the **Wall** preset and press F11. It has the old wall layout: the Detailed dashboard's summary tiles across the top, the Cluster Map on the left, the CPU-by-node chart and the automation banner with its recent checks on the right.

## Overview

- **Three widgets from the Detailed dashboard:** Summary tiles (the KPI row), Node chart (every node for CPU, memory or IO wait, with the threshold line and spread readout), and Automation status (the banner, recent checks and data age).
- **Taller widgets:** in Arrange, drag a widget's bottom edge or use **− ↕ +** to make it 1 to 4 rows tall. Smaller widgets stack beside it and stretch to its height, for example two or three widgets next to a tall Cluster Map.
- **Charts fill their widget** in both directions. The load chart, node chart, memory map, forecast, and the moves and backups per day grow when a widget is made taller, not only wider.

## Smaller fixes

- On the Cluster Map, the tooltip of the guest you hover is no longer covered by the suggested-move arrows.
- New screenshots in the README and docs: the Overview, the Charts preset, Arrange, the Overview on a phone, the map's affinity hover and the guest panel's backups.

## Upgrading

Update from the update window (click the version number in the top bar). The updater backs up the database, settings and web files, installs the tested web bundle, restarts ProxBalance and rolls back automatically if it doesn't come back healthy. Overview layouts saved in a browser are kept.
